# Module 4: Vision-Language-Action (VLA)

## Focus: The Convergence of LLMs and Robotics
The final module integrates large language models (LLMs) with robotics to create intelligent, conversational agents capable of complex tasks. 

### Key Concepts:
* Voice-to-Action: Using OpenAI Whisper for voice commands.
* Cognitive Planning: Using LLMs to translate natural language into a sequence of ROS 2 actions.
* Capstone Project: The Autonomous Humanoid.
