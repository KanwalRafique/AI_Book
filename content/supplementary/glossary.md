# Glossary: Physical AI & Humanoid Robotics

This glossary provides definitions for key terms used throughout the book, helping you navigate the complex terminology of Physical AI and Humanoid Robotics.

## A

**Action (ROS 2)**: A long-running, goal-oriented communication mechanism in ROS 2 that provides periodic feedback on its progress and a final result.

**AI (Artificial Intelligence)**: The simulation of human intelligence processes by machines, especially computer systems.

**ASR (Automatic Speech Recognition)**: Technology that allows computers to understand spoken language and convert it into text.

## B

**Bipedal Movement**: Locomotion on two feet, a characteristic of humanoid robots.

**Bounding Box**: A rectangular frame that tightly encloses an object in an image, typically used in object detection.

## C

**Cognitive Planning**: The process by which a robot understands a high-level task, breaks it down into sub-goals, and generates a sequence of actions to achieve those sub-goals.

**Costmap**: A 2D or 3D grid representation of an environment used in robot navigation, where each cell is assigned a "cost" indicating its traversability.

**CUDA**: NVIDIA's parallel computing platform and programming model that enables dramatic increases in computing performance by harnessing the power of the graphics processing unit (GPU).

## D

**DDS (Data Distribution Service)**: An industry standard for real-time, high-performance, and scalable data-centric communication, used as the underlying transport layer in ROS 2.

**Digital Twin**: A virtual model designed to accurately reflect a physical object, system, or process.

**Docusaurus**: An open-source static site generator for building documentation websites.

## E

**Embodied AI**: Artificial intelligence systems that exist within a physical body (like a robot) and interact with the physical world.

**Entities (NLU)**: Specific pieces of information extracted from natural language commands, such as objects, locations, or numerical values.

## F

**FastAPI**: A modern, fast (high-performance) web framework for building APIs with Python 3.7+ based on standard Python type hints.

## G

**Gazebo**: A powerful 3D robot simulator that allows for accurate simulation of robots in complex environments.

**GPU (Graphics Processing Unit)**: A specialized electronic circuit designed to rapidly manipulate and alter memory to accelerate the creation of images in a frame buffer for output to a display device.

## H

**HRI (Human-Robot Interaction)**: The study of interactions between humans and robots.

**Humanoid Robot**: A robot with its overall shape based on that of the human body.

## I

**IMU (Inertial Measurement Unit)**: An electronic device that measures and reports a body's specific force, angular rate, and sometimes the orientation of the body, using a combination of accelerometers and gyroscopes.

**Intent (NLU)**: The goal or purpose behind a user's natural language command.

**Isaac ROS**: A collection of hardware-accelerated ROS 2 packages developed by NVIDIA for high-performance perception and navigation.

**Isaac Sim**: A scalable, cloud-native robot simulation application built on NVIDIA Omniverse for physically accurate and photorealistic virtual environments.

## J

**Joint (URDF)**: Describes the kinematic and dynamic properties of the connection between two links in a robot model.

## L

**LiDAR (Light Detection and Ranging)**: A remote sensing method that uses pulsed laser light to measure distances and create precise 3D information about the Earth's surface and object characteristics.

**Link (URDF)**: Represents a rigid part of a robot, defined by its visual, collision, and inertial properties.

**Localization**: The process of determining a robot's own position and orientation within a known map.

## M

**Markdown**: A lightweight markup language for creating formatted text using a plain-text editor.

**MDX**: Markdown with JSX, allowing React components to be embedded directly within Markdown content.

## N

**Nav2 (Navigation2)**: The standard navigation stack for ROS 2, providing a framework for autonomous robots to navigate environments.

**NLU (Natural Language Understanding)**: A subfield of AI that focuses on enabling computers to understand and interpret human language.

**Node (ROS 2)**: An independent executable program in ROS 2 that performs a specific task.

## O

**OpenAI Whisper**: An open-source automatic speech recognition (ASR) system from OpenAI, known for its high accuracy and robustness.

## P

**Perception**: The process by which a robot senses and interprets its environment using sensor data.

## Q

**Qdrant**: A vector similarity search engine and vector database that provides a production-ready service with a convenient API to store, search, and manage points (vectors) with an additional payload.

## R

**RAG (Retrieval-Augmented Generation)**: An AI framework that retrieves information from an external knowledge base to inform the generation of responses by a large language model.

**`rclpy`**: The Python client library for ROS 2.

**ROS 2 (Robot Operating System 2)**: An open-source middleware that provides a flexible framework for writing robot software.

## S

**SDF (Simulation Description Format)**: An XML format used in Gazebo to describe robots, environments, and other simulation elements. More expressive than URDF.

**Semantic Segmentation**: A computer vision task that involves classifying each pixel in an image into a predefined category, often used for understanding the scene layout.

**Sensor Simulation**: The process of creating virtual sensors that mimic the behavior of real-world sensors in a simulated environment.

**Service (ROS 2)**: A request/reply communication mechanism in ROS 2, used for tasks that require an immediate response.

**SLAM (Simultaneous Localization and Mapping)**: The computational problem of constructing or updating a map of an unknown environment while simultaneously keeping track of an agent's location within it.

**STT (Speech-to-Text)**: See ASR.

**Synthetic Data Generation**: The process of artificially creating data that mimics the statistical properties of real-world data, often used for training AI models.

## T

**Topic (ROS 2)**: A publish/subscribe communication mechanism in ROS 2, used for streaming data asynchronously.

**Twist (geometry_msgs/Twist)**: A standard ROS message type used to represent linear and angular velocity commands for a robot.

## U

**Unity**: A popular cross-platform game engine often used for creating 3D visualizations and interactive applications, including robotics simulations.

**URDF (Unified Robot Description Format)**: An XML format used in ROS to describe the kinematic and dynamic properties of a robot.

## V

**Vector Database**: A database optimized for storing and querying vector embeddings, often used in RAG systems.

**Vision-Language-Action (VLA)**: An AI paradigm where robots use visual perception and natural language understanding to perform actions in the physical world.

**VSLAM (Visual Simultaneous Localization and Mapping)**: SLAM performed primarily using visual sensor data (e.g., from cameras).

## W

**Whisper (OpenAI)**: An open-source automatic speech recognition (ASR) system from OpenAI.

## Z

**ZMP (Zero Moment Point)**: A concept used in robotics to describe the point on the ground about which the net moment of all forces (gravity, inertia, and contact forces) is zero, crucial for maintaining dynamic balance in bipedal robots.
